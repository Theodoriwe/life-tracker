Создай персональное PWA-приложение (Progressive Web App) — mobile-first, оптимизированное для добавления на главный экран телефона. Приложение на русском языке.

---

## АРХИТЕКТУРА И СИНХРОНИЗАЦИЯ

Все данные хранятся в localStorage и синхронизируются через Telegram Bot как бэкенд:
- При каждом изменении данных отправлять JSON-обновление в Telegram Bot через Bot API (токен и chat_id вводятся пользователем в Настройках при первом запуске)
- При загрузке приложения — получать последний снимок данных из Telegram (последнее сообщение бота с тегом #DATA_SYNC)
- Telegram выступает как простое облачное хранилище вместо базы данных

## ДИЗАЙН-СИСТЕМА

**Стиль:**
- Светлый фон: #FFFFFF основной, #F7F7F5 для карточек и панелей
- Типографика: Inter или SF Pro Display — чистая, высококонтрастная
- Никаких градиентов
- Никаких эмодзи — только премиальные минималистичные SVG-иконки (линейный стиль, обводка 1.5px, монохром)
- Один акцентный цвет: глубокий тёмно-синий #1A1A2E или тёплый графит #2D2D2D
- Только микро-тени: box-shadow максимум 0 2px 8px rgba(0,0,0,0.06)
- Скругление углов: 16px для карточек, 12px для кнопок, 8px для полей ввода
- Сетка отступов: кратно 8px
- Весь текст читается на расстоянии вытянутой руки на экране 390px

**Взаимодействия:**
- Плавные переходы: 200ms ease
- Долгое нажатие (600мс) запускает специальные действия (например, отметить выполненным)
- Визуальная обратная связь при касании (лёгкое сжатие scale 0.97)
- Нижняя навигационная панель с 5 вкладками — всегда видима, с учётом safe area

## НАВИГАЦИЯ

Нижняя панель с 5 вкладками:
1. Главная (иконка домика)
2. Работа (иконка таймера)
3. Цели (иконка мишени)
4. Питание и дневник (иконка листа или вилки)
5. Привычки (иконка цепочки)

---

## ВКЛАДКА 1 — ГЛАВНАЯ

Сводка важнейших данных из всех вкладок за сегодня.

Блоки сверху вниз:
- Приветствие + текущая дата (например, «Доброе утро. Четверг, 26 июня»)
- Блок работы: часов отработано сегодня из дневной цели — тонкий горизонтальный прогресс-бар с подписью «X ч из Y ч цели»
- Топ-3 задачи на сегодня из вкладки Цели — кликабельные, с долгим нажатием для завершения
- Блок калорий: потреблено из дневной нормы — кольцевая диаграмма, компактно
- Активные таймеры привычек: каждая активная привычка — компактная карточка с таймером (дней/часов с последнего срыва)
- Самочувствие: последняя оценка из 10, кнопка «Записать» если сегодня ещё не отмечено

---

## ВКЛАДКА 2 — РАБОТА

Отслеживает время работы за компьютером (данные присылает внешний скрипт отслеживания мышки через Telegram Bot).

**Вид «Сегодня»:**
- Крупный дисплей времени: часы и минуты отработано сегодня
- Кольцо дневной цели: круговой прогресс, цель устанавливается нажатием на центр кольца
- Список сессий: каждая рабочая сессия — таблетка с диапазоном времени (например, «10:14 – 12:38 · 2ч 24м»)
- Индикатор текущей сессии: живой бейдж «Сейчас активна — 1ч 12м» если сессия идёт

**Вид «Статистика» (переключатель):**
- Столбчатый график: последние 7 дней — столбцы показывают часы, линия цели поверх
- Среднее за неделю и месяц под графиком
- Счётчик стрика: «X дней подряд выполняю цель» с SVG-иконкой огня
- Выделение лучшего дня

**Установка цели:**
- Нажать на кольцо цели или кнопку «Установить дневную цель»
- Ползунок или поле ввода: задать часы (например, 6ч)

---

## ВКЛАДКА 3 — ЦЕЛИ И ЗАДАЧИ

**Структура:**
- Цели разделены на три группы: Сегодня / На этой неделе / Долгосрочные
- Карточка цели: название, дедлайн (опционально), прогресс-бар (считается автоматически по подзадачам), цветная точка приоритета (красный/жёлтый/зелёный)
- Нажатие на цель — разворачивает её: подзадачи, добавление подзадач, редактирование

**Добавление цели:**
- FAB-кнопка (плавающая) внизу справа
- Поля: Название, Дедлайн (выбор даты), Приоритет, Добавить подзадачи
- Подзадачи — чеклист внутри цели

**Завершение цели:**
- Долгое нажатие (600мс) запускает анимацию заполнения — фон карточки заполняется слева направо за 2 секунды
- Отпустить до 2с — отмена
- После 2с — цель отмечена выполненной (карточка сжимается и уходит в архив)
- Встряска или кнопка «Отменить» (видна 4 секунды после выполнения) для восстановления

**Повторяющиеся задачи:**
- Переключатель «Повторять» при создании — варианты: Ежедневно, Еженедельно, Выбрать дни
- Сбрасываются автоматически в полночь

**Архив:**
- Кнопка в шапке — показывает выполненные цели с датой

## ВКЛАДКА 4 — ПИТАНИЕ И ДНЕВНИК

Два подраздела внутри вкладки: **Питание** и **Дневник** — переключатель в виде горизонтальных таблеток вверху

### Подраздел: ПИТАНИЕ

**Моё меню:**
- Сохранённый список разрешённых/любимых блюд
- Сгруппировано по: Завтрак / Обед / Ужин / Перекус
- Каждое блюдо: название, калории, КБЖУ
- Добавить блюдо: название, тип приёма пищи, калории, белки, жиры, углеводы
- Теги (опционально): «лёгкое», «быстро», «без глютена»

**Дневник питания:**
- Разделы по типу приёма пищи
- Кнопка «Добавить» в каждом разделе — открывает поиск продуктов
- Поиск продуктов: использует Open Food Facts API (https://world.openfoodfacts.org/cgi/search.pl) — поиск по названию, возвращает калории и КБЖУ на 100г, пользователь вводит размер порции
- Кнопка «Повторить вчерашний завтрак» — копирует записи предыдущего дня для этого типа приёма пищи
- Итоговая панель внизу: итого ккал / белки / жиры / углеводы — цветные прогресс-бары относительно дневной нормы
- Трекер воды: ряд из 8 кружков, нажать чтобы заполнить (каждый = стакан 250мл)

**Дневные нормы:**
- Задаются в Настройках: дневная норма ккал, цели по белкам/жирам/углеводам

### Подраздел: ДНЕВНИК (Самочувствие)

**Добавить запись:**
- Большая кнопка «+» вверху
- Поля:
  - Время (проставляется автоматически, можно изменить)
  - Оценка самочувствия: 1–10 крупный выбор таблетками-кнопками
  - Быстрые теги симптомов (мультивыбор): Вздутие, Тяжесть, Изжога, Тошнота, Высокая энергия, Низкая энергия, Головная боль, Туман в голове — плюс поле для заметки
- Кнопка «Сохранить»

**Хронология:**
- Записи в хронологическом порядке, сгруппированы по дням
- Каждая запись: время, бейдж оценки (цветовая кодировка: 1–4 красный, 5–7 жёлтый, 8–10 зелёный), активные теги, фрагмент заметки

**Умные инсайты (корреляция еда → самочувствие):**
- После сохранения записи с оценкой ≤ 5 приложение проверяет приёмы пищи за последние 60–120 минут
- Если конкретный ингредиент встречается в 5+ эпизодах с низкой оценкой — показывается мягкое предупреждение: «Возможная реакция: [ингредиент] предшествовал [X] записям с низким самочувствием»
- Раздел «Инсайты» вверху подраздела Дневник
- Список «Подозреваемые продукты» — каждый можно скрыть

## ВКЛАДКА 5 — ПРИВЫЧКИ

**Добавить привычку для отказа:**
- Кнопка «+»
- Поля: Название привычки (например, «Курение»), Ежедневные траты (опционально, например 300₽/день), Время последнего срыва (выбор даты и времени), Заметки
- Выбор иконки: небольшой набор SVG-иконок (сигарета, телефон, напиток, сахар и т.д.)

**Карточка привычки:**
- Название + иконка
- Крупный таймер: «X дней X часов X минут» с момента последнего срыва — обновляется в реальном времени
- Личный рекорд: самая длинная серия (под таймером)
- Сэкономлено денег: считается как траты в день × дней без срыва
- Эквивалент: «Это примерно X походов в ресторан» (сэкономлено ÷ 1500₽)
- Статус-бар: тонкая цветная линия — текущая серия относительно рекорда

**Кнопка срыва:**
- Нажать на карточку — открывается детальный вид
- Красная кнопка «Сорвался» — требует свайпа для подтверждения (свайп вправо, защита от случайного нажатия)
- При подтверждении: таймер сбрасывается, срыв фиксируется с временной меткой, сохраняется в истории
- Предыдущий рекорд сохраняется

**История и паттерны:**
- Разворачиваемый раздел для каждой привычки
- Список всех срывов с временными метками
- График паттернов срывов: точечный по дню недели и времени суток — помогает понять когда срываешься чаще
- Выделение самой длинной серии

## ЭКРАН НАСТРОЕК

Иконка шестерёнки в правом верхнем углу на Главной.

Поля:
- Токен Telegram Bot (текстовое поле)
- Telegram Chat ID (текстовое поле)
- Кнопка «Проверить подключение»
- Дневная цель по работе (часы)
- Дневная норма калорий + КБЖУ
- Цель по воде (стаканы)
- Имя пользователя (используется в приветствии)

## ОБЩИЕ ПРАВИЛА UX

- Любое деструктивное действие требует подтверждения (свайп, долгое нажатие или модальное окно)
- Пустые состояния: в каждой вкладке — дружелюбная SVG-иллюстрация с коротким текстом и кнопкой призыва к действию
- Все списки прокручиваются с инерцией, без пагинации
- Минимум модальных окон — предпочтительно инлайн-раскрытие или нижние шторки (bottom sheets)
- Нижняя шторка: выезжает снизу, размытый фон, ручка-тяга вверху
- Состояния загрузки: только скелетные экраны (без спиннеров)
- Состояния ошибок: тихое красное сообщение inline, без алертов
- Все данные сохраняются автоматически при изменении — явной кнопки «Сохранить» нет, кроме Настроек
